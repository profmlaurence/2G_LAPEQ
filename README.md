# Optimizer LAPEQ 🚀

Este software tem o objetivo de otimizar a produção de bioetanol de segunda geração (2G) utilizando algoritmos inteligentes no âmbito de aprendizado de máquinas profundos (*deep learning*).

## Funcionalidades ✨

### Treinamento 📚
Nesta etapa, o usuário pode adicionar o *dataset* para treinamento, escolhendo o modelo de *machine learning* que o **Optimizer LAPEQ** usará.

### Predição 🔮
A etapa de predição será usada para determinar a melhor configuração para a produção de glicose/bioetanol a partir da biomassa disponível.
